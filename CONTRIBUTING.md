# Contributing

Corrections that make the steps safer, clearer, or more current are welcome.

## Before submitting

- Check the official Obsidian, OpenAI, and tunnel-client references linked in the guide.
- Keep instructions general and avoid assumptions about a particular person's vault, account, operating system, or credentials.
- Use placeholders such as `<your-plugin-key>` in examples. Never include real keys, tokens, private endpoints, vault contents, or personal file paths.
- State which product/version your change applies to when behavior differs by version.
- Prefer small changes with a clear commit message.

## Change process

1. Open an issue for a substantial change or propose a focused pull request.
2. Explain the user-visible change and include official references for behavior that may change over time.
3. Review the diff for secret values and personal data before publishing.

By contributing, you agree that your contribution is offered under the repository's Creative Commons Attribution 4.0 International license.
