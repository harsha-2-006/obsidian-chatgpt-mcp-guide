# Security policy

## Scope

This repository contains setup documentation, not executable software. Report unsafe or misleading instructions, suspected secret exposure, or account compromise privately where possible.

## Do not disclose secrets in public

Do not open a public issue or pull request containing API keys, bearer tokens, tunnel runtime credentials, private endpoints, vault contents, or personal information. If a secret was published, revoke or rotate it immediately with the provider, remove it from the repository history where appropriate, and notify the maintainers privately.

## Reporting

For a security concern, use GitHub's private vulnerability reporting for this repository if enabled. Otherwise contact the repository owner through a private channel listed on their GitHub profile. Include a concise description and safe reproduction details; do not send credentials.

## Reader safeguards

Use the least access needed, begin with read-only tools, keep credentials out of source control, and do not expose the local Obsidian API endpoint to the public internet. Review MCP tool permissions before enabling access.
